# استبيان الشك للشباب — نسخة Vercel

تلات صفحات + دالتين serverless. مفيش build ولا dependencies.

```
doubt-survey/
├── index.html        الاستبيان بس — ده اللينك اللي يتبعت للشباب
├── results.html      النتايج المجمّعة لايف — ده ليكي إنتي
├── qr.html           مولّد الـ QR بعد الرفع — ليكي إنتي كمان
├── api/submit.js     يستقبل إجابة واحدة ويخزّنها
├── api/stats.js      يرجّع الإحصائيات المجمّعة بس
├── package.json
└── README.md
```

## ١. الجدول في Supabase

لو عندك مشروع Supabase من استبيان القلق، استخدمي **نفس المشروع ونفس المفاتيح** — الجدول ده اسمه مختلف فمش هيتعارض معاه. افتحي **SQL Editor** ونفّذي:

```sql
create table doubt_responses (
  id          bigint generated always as identity primary key,
  respondent  text unique not null,
  answers     smallint[] not null,
  total       smallint not null,
  level       smallint not null,
  created_at  timestamptz not null default now()
);

alter table doubt_responses enable row level security;
-- من غير أي policy: الـ service key بتاع السيرفر هو اللي بيوصل بس
```

## ٢. الرفع على Vercel

ده **مشروع منفصل** عن استبيان القلق (عشان كل واحد يبقى له لينك لوحده). ارفعي فولدر `doubt-survey` كمشروع جديد، وضيفي نفس المتغيرين قبل الـ Deploy:

| الاسم | القيمة |
| --- | --- |
| `SUPABASE_URL` | الـ Project URL |
| `SUPABASE_SERVICE_KEY` | الـ service_role key |

وبعد الـ Deploy هيبقى عندك:

| اللينك | لمين |
| --- | --- |
| `https://doubt-survey.vercel.app` | **للشباب** — الاستبيان بس |
| `https://doubt-survey.vercel.app/results.html` | **ليكي** — النتايج لايف |
| `https://doubt-survey.vercel.app/qr.html` | **ليكي** — مولّد الـ QR |

## ٣. الـ QR كود

افتحي `qr.html` (من اللينك أو حتى من جهازك بالضغط عليه مرتين — بيشتغل من غير إنترنت)، والصقي لينك الاستبيان ودوسي **اعمل الكود**. هيطلعلك كارت فيه لوجو الاجتماع والعنوان والكود، وقدامك تلات اختيارات:

- **نزّل الكود صورة PNG** — تحطيها في بوست أو ستوري أو بنر.
- **اطبع الكارت** — صفحة جاهزة للطباعة تتعلّق في الكنيسة أو تتحط على الترابيزة.
- أو صوّري الشاشة ببساطة وابعتيها في جروب الواتساب.

الشاب بيفتح كاميرا موبايله ويوجّهها على الكود، فيظهرله إشعار يدوس عليه ويفتح الاستبيان على طول من غير ما يكتب أي لينك.

> اختاري حجم **«كبير جداً»** لو الكود هيتطبع في بنر أو هيتصوّر من بعيد.

## ملاحظات

- **الخصوصية:** مفيش اسم ولا إيميل ولا IP بيتخزن. كل جهاز بياخد معرّف عشوائي محلي، فلو نفس الشخص جاوب تاني من نفس الموبايل بتتحدّث إجابته بدل ما تتسجّل مرتين.
- **الموضوع حساس أكتر من القلق:** حدّ الشاب إنه يقول «أنا بشك» صعب جداً جوّه الكنيسة. اوعدي الشباب بوضوح إن الورقة مجهولة ومحدش هيتسأل، وسيبي الباب مفتوح لحد عايز يتكلم على جنب — من غير ما حد يتسمّى قدام الناس.
- **التحديث اللايف:** صفحة النتايج بتسأل السيرفر كل ٥ ثواني لوحدها.
- **تصفير النتايج قبل اجتماع جديد:** في SQL Editor نفّذي `truncate table doubt_responses;`
- **سحب البيانات:** Supabase → Table Editor → Export CSV.
- **تعديل الأسئلة:** في مصفوفة `Q` في أول السكريبت. لو غيّرتي سؤال، غيّريه في `index.html` و`results.html` (في results الاختيارات مختصرة عشان تبان في الرسم).
